**Semantics (from the spec, verbatim values):**

- Count mode, `index="features"`: eager output has one row per input row; row t is `[X[t]..., y[t + count]]`, and the last `count` rows have a NaN target. `index="target"` is today's behavior unchanged: row t is `[X[t - count]..., y[t]]`, first `count` feature rows NaN.
- Duration mode, `index="features"`: one row per X event, in X order. Row for the X event at index t holds `X[t]` and the value of the last y event whose index is at or before `t + duration` (inclusive; for several y events at one index, the last of them). The target is NaN when no y event has index at or before `t + duration`, and NaN when `t + duration` is after the last y event's index. `index="target"` is today's behavior unchanged.
- Lazy and graph regimes, `index="features"`: a row is emitted only once its target is known (count mode: `count` later rows have arrived; duration mode: y has passed `t + duration`), stamped with the features' index t; stamps are non-decreasing; the node forwards as watermark the stamp of its oldest pending row (or the incoming watermark when nothing is pending). `flush()` emits the pending rows, in order, with a NaN target. Pending memory is at most `count` rows (count mode).
- `dropna=True` applies after pairing, as today.
- With `dropna=True` in count mode, `index="features"` and `index="target"` return identical arrays.
- Graph JSON: `to_dict` always writes `index`; a `forecast_pairs` node without `index` loads as `"target"` (the behavior of the version that saved it).

Implementation guidance: count mode can reuse the existing `CombineLatest(X, y, when_all)` and add a node after it that keeps a ring of `count` pending `[X..., y]` rows with their indices: on each new row it emits `[oldest X..., new y]` stamped with the oldest row's index, then stores the new row; `flush` drains the ring with NaN targets. For duration mode, `Delay(-duration)` on y turns "y at or before t + duration" into an as-of at t on the X clock; a dedicated node is the simplest way to get the inclusive as-of and the NaN tail together (pending X rows are resolved when a y event with a later stamp arrives or at flush; at flush, a row is resolved only if a y stamp at or after t was seen). Follow the conventions of `lag_rows_node.h` (width set by the first event, exception safety, ring reuse on reset) and `delay_node.h`. Check that the eager driver, the lazy driver, and `Pipeline` (including live sessions) all compile the new node(s).

def _ref_features_count(X, y, h):
    """Row t: X[t] and y[t + h]; NaN target for the last h rows."""
    X = np.asarray(X, float); y = np.asarray(y, float)
    yt = np.full(len(y), np.nan)
    yt[:len(y) - h] = y[h:]
    return X, yt


def _ref_features_duration(xv, xi, yv, yi, d):
    """One row per X event: X[t] and the last y at or before t + d; NaN past the last y."""
    out = np.full(len(xv), np.nan)
    if len(yi):
        for k, t in enumerate(xi):
            if t + d > yi[-1]:
                continue
            j = np.searchsorted(yi, t + d, side="right") - 1
            if j >= 0:
                out[k] = yv[j]
    return np.asarray(xv, float), out

Task 4 consumes them through the WASM manifest; Tasks 5 to 7 document and use them.

**Exact behavior** (spec, section `TripleBarrier`):

For each entry step e with entry price `p_e` (the price, or the close) finite and > 0:

- Barrier levels: `"fraction"`: `U = p_e * (1 + upper)`, `L = p_e * (1 - lower)`; `"price"`: `U = p_e + upper`, `L = p_e - lower`; `"vol"`: `U = p_e * (1 + upper * s)`, `L = p_e * (1 - lower * s)` with `s = sigma_h(e)`. A barrier set to 0 is off (`U = +inf`, `L = -inf`).
- `sigma_h(e) = EwStd(span=vol_span)` of the one-step log returns `log(p_k / p_{k-1})` up to and including e, times `sqrt(horizon)`. Use screamer's `EwStd` class internally (`include/screamer/ew_std.h`). If `s` is NaN or not > 0, the entry's outputs are NaN.
- Walk k = 1 .. horizon. Price-only: `q = p_{e+k}`; if q is NaN or <= 0 the entry's outputs are NaN; if `q >= U`: label +1, exit q; else if `q <= L`: label -1, exit q. OHLC, bar `e+k` with `(o, h, l, c)`, any of them NaN or <= 0 gives NaN outputs: if `o >= U`: +1, exit o; else if `o <= L`: -1, exit o (gap at the open); else if `h >= U` and `l <= L`: NaN outputs (both inside one bar); else if `h >= U`: +1, exit `clamp(U, l, h)`; else if `l <= L`: -1, exit `clamp(L, l, h)`.
- No barrier within the horizon: label 0, exit at `p_{e+horizon}` (OHLC: `close[e+horizon]`), holding `horizon`.
- `return = exit / p_e - 1`, `holding = k` at the exit.
- Output at step t is the entry `e = t - horizon`; the first `horizon` outputs are NaN. Prices after an entry's exit do not affect it.
- Checks (`std::invalid_argument`): `horizon >= 1` (`IntArg`, minimum in `common/int_settings.h` if that is how other ops declare minimums), `upper` and `lower` finite and >= 0, `lower < 1` when `barrier_unit == "fraction"`, `vol_span >= 1`, `barrier_unit` one of the three strings (message lists them).
- State: a ring of `horizon + 1` entry records (entry price, levels, resolved flag/outputs) plus the `EwStd`; each step updates the unresolved entries, so O(horizon) per step. `reset()` restores the initial state.
- Frontmatter: `inputs: 1` / `4`, `outputs: 3`, `output_names: [label, return, holding]`, `nan_policy: nan-aware` (as the backtest engines), `start_policy` as the compliance tests require for a strict `horizon` warm-up, `topics: [supervised]`, `see_also: [forecast_pairs, BacktestOHLCTarget, LogReturn]`, a parameter entry for each setting with `min:` where it applies. The page body: what the label is (three states over a window, no position), the stamping rule ("the output at step t is the entry at t - horizon; pair it with `forecast_pairs(X, y, count=horizon)`"), the three units, the OHLC rules, meta-labeling as a two-line recipe (`label == side`), and a plot of labels on a price chart (follow how other `functions_fin` pages make their plots and gallery thumbnails).

```python
"""Triple-barrier labels written as a plain loop over entries."""
import numpy as np
import pandas as pd


def _levels(p, upper, lower, unit, s):
    if unit == "fraction":
        U, L = p * (1 + upper), p * (1 - lower)
    elif unit == "price":
        U, L = p + upper, p - lower
    else:
        U, L = p * (1 + upper * s), p * (1 - lower * s)
    return (U if upper > 0 else np.inf), (L if lower > 0 else -np.inf)


def _sigma(price, vol_span, horizon):
    r = np.log(price[1:] / price[:-1])
    s = pd.Series(np.r_[np.nan, r]).ewm(span=vol_span).std().to_numpy()
    return s * np.sqrt(horizon)


class TripleBarrier_numpy:
    def __init__(self, horizon=20, upper=0.0, lower=0.0, barrier_unit="fraction", vol_span=100.0):
        self.h, self.up, self.lo, self.unit, self.span = horizon, upper, lower, barrier_unit, vol_span

    def __call__(self, price):
        p = np.asarray(price, float)
        n, h = len(p), self.h
        out = np.full((n, 3), np.nan)
        sig = _sigma(p, self.span, h) if self.unit == "vol" else np.ones(n)
        for e in range(n - h):
            pe, s = p[e], sig[e]
            if not (np.isfinite(pe) and pe > 0) or not (np.isfinite(s) and s > 0):
                continue
            U, L = _levels(pe, self.up, self.lo, self.unit, s)
            res = None
            for k in range(1, h + 1):
                q = p[e + k]
                if not (np.isfinite(q) and q > 0):
                    break
                if q >= U:
                    res = (1.0, q, k); break
                if q <= L:
                    res = (-1.0, q, k); break
                if k == h:
                    res = (0.0, q, k)
            if res is not None:
                out[e + h] = (res[0], res[1] / pe - 1.0, res[2])
        return out
```
